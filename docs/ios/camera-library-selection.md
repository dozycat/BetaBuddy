# 相册归集、人物选择与剪辑进度

本轮在独立分支 `codex/camera-library-selection` 实现；完整目标包含以下三部分，不能以其中一项完成代替整个目标。

## 需要交付

1. 用户启用后，在授权的系统相册范围内自动发现并导入攀爬视频。识别室内／室外，支持纠正；以视频拍摄时间及视频的位置推荐岩馆，按天和馆自动聚合。不得用当前手机的位置猜旧视频的拍摄地点。扫描应可停止、增量恢复、去重，删掉的记录不能立即被扫描重新导入。兼容有限照片授权、拒绝／撤销授权、无位置／日期、云端原片不可用、资源被删除／编辑、存储失败和取消。系统相册原片不改动。
2. 自动选取攀爬者，并允许用户直接点选人、在其他时间纠正。采用轻量圈线，保留背景，不使用整幅压暗。选择必须影响姿态分析、跟拍和成片，不能只画 UI。多人交叉、遮挡、重新出现时不能悄悄换人；无法确认时保留缺失。选择和纠正随记录保存，重新分析仍有效，改选后旧分析／剪辑计划需要失效。
3. 用品牌已有的岩点轮廓和绳线表现剪辑进度，动作跟随真实工作进度。可取消、失败后重试，适配读屏、减少动态效果及大字号。不要做不断自行走满的假进度。

两端保持相同产品行为。平台权限及推理接口可以不同。攀岩识别／自动选人判断属于私有数据包；原生负责通用媒体读取、系统识别结果、交互、存储和渲染。不得把私有场馆和算法写进应用仓库。

## 当前实际进度

- 已建立独立 worktree，基于全屏相机的主分支版本。
- 两端剪辑页已接入绳线与上升岩点，数值取实际渲染回调；iOS 遵守减少动态效果设置，Android 没有循环运动。
- 两端攀爬册已按拍摄日和馆分组；变更记录日期／馆后重新计算，用户文件夹保留独立。室外和未知环境不会混成一组；环境字段兼容旧存档。
- 相册自动扫描／分类／导入、人物选择及其分析链路还未接入，目标尚未完成。
- 自动化、截图与真机证据将逐条补充。没有结果的项目不记为通过。

## 完成时必须验证

- 用真实攀爬与非攀爬素材核对自动发现和室内外判断；含室内、室外、多人、遮挡，记录误判与漏检，不能用合成夹具证明识别准确率。
- 相册授权后自动导入、有限授权新增、撤销权限、增量扫描、去重、删除后不自动回流；失败不丢原视频。
- 按拍摄日和推荐馆分组；用户纠正馆、日期和室内外后立刻重新聚合，跨日／跨时区边界和缺失元数据有测试。
- 真实多人片段的自动选择、点选、遮挡和重新出现；画面圈线与送去分析的人、成片跟拍同一人。旧记录兼容，改选使缓存失效，取消不改变之前选择。
- 两端渲染中的真实进度、取消、失败、重试和成片；读屏、减少动态效果、大字号与窄屏截图。
- Swift 核心测试、iOS 单元／集成／UI、未签名设备构建；Android 资源检查、单元测试、Debug 构建及对应界面验证。按实际证据记录平台差异和未测范围。

## 2026-11-28 验证

- Swift 核心 37 项通过，新增分组检查包含拍摄日期优先于导入日期、同名不同馆、修改日期后移动分组、室外／未知分开，以及 25 小时夏令时回退日。
- iOS 定向单元／集成 18 项及文件夹／导航 UI 6 项通过；较长 720p 合成片段的剪辑 UI 另跑 1 项通过。已查看真实渲染中 21% 的截图，绳线、岩点、百分比和取消入口正常；不是静态设计稿。
- Android 272 条五语言资源检查、190 项单元测试和 Debug 构建通过。Android 新界面尚未在模拟器／真机上查看；大字号、窄屏、读屏及减少动态效果仍需专门验收。
- iOS 未签名设备构建通过。未追加真机验证。
- 探索相册分类时，系统通用图片分类在一条已知攀爬参考片段上的判断很弱，未接进自动导入。私有仓库已准备另一种离线模型候选的可复跑评估／导出工具；同一片段五帧匹配室内攀爬。Core ML 与 ONNX 导出和参考推理的数值对照通过，但这只有一个真实正例，不是准确率验收。
