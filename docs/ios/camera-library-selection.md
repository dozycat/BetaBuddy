# 相册归集、人物选择与剪辑进度

本轮在独立分支 `codex/camera-library-selection` 实现；完整目标包含以下三部分，不能以其中一项完成代替整个目标。

## 需要交付

1. 用户启用后，在授权的系统相册范围内自动发现并导入攀爬视频。识别室内／室外，支持纠正；以视频拍摄时间及视频的位置推荐岩馆，按天和馆自动聚合。不得用当前手机的位置猜旧视频的拍摄地点。扫描应可停止、增量恢复、去重，删掉的记录不能立即被扫描重新导入。兼容有限照片授权、拒绝／撤销授权、无位置／日期、云端原片不可用、资源被删除／编辑、存储失败和取消。系统相册原片不改动。
2. 自动选取攀爬者，并允许用户直接点选人、在其他时间纠正。采用轻量圈线，保留背景，不使用整幅压暗。选择必须影响姿态分析、跟拍和成片，不能只画 UI。多人交叉、遮挡、重新出现时不能悄悄换人；无法确认时保留缺失。选择和纠正随记录保存，重新分析仍有效，改选后旧分析／剪辑计划需要失效。
3. 用品牌已有的岩点轮廓和绳线表现剪辑进度，动作跟随真实工作进度。可取消、失败后重试，适配读屏、减少动态效果及大字号。不要做不断自行走满的假进度。

两端保持相同产品行为。平台权限及推理接口可以不同。攀岩识别／自动选人判断属于私有数据包；原生负责通用媒体读取、系统识别结果、交互、存储和渲染。不得把私有场馆和算法写进应用仓库。

## 2026-11-28 · iOS 人物选择开发链路

- 回看页新增「选择攀爬者」。多姿态候选和粗略衣着色样在本机生成，自动选择由私有数据包决定。圈线保留原视频背景，可拖动时间、点选、自动选择、在另一个时刻纠正；取消不写入选择，保存后保留选人标记。
