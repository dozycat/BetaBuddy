# BetaBuddy iPhone · 产品与交互设计

## 产品性格

「再试一次。这次，有点不一样。」不是万能 AI 教练，而是懂攀岩节奏的随身伙伴：在岩馆里看一条线换个身材怎么爬，上墙试，把这一趟录下来回看，记一句下次想改的地方。成功、尝试、复盘都有位置。没有排行榜压力、虚构分数、连续打卡焦虑或首次打开的大段配置。

视觉语言：暖纸白 #F5F2E8、墨黑 #1A1F1A、荧光黄绿 #D1F24A、淡紫 #D1CCF0。超粗标题、紧凑英文运动标记配正文说明；倾斜的开口攀岩扣作为品牌标志，配合岩点与攀爬剪影形成自己的视觉识别。插画和图标为本地矢量绘制，不依赖远程图片。圆角控制在 14–26pt，强调色用于主行动与当前选择。

## 两个入口

- **岩馆**：应用打开就在这里。一家真实岩馆的 3D 线路图与「不同身材怎么爬这条线」的推演，来自随安装包内置的场馆数据包。非官方；推演不是建议。没有数据包的构建显示说明。设计与接口约定见 [gym-design.md](gym-design.md)。
- **攀爬册**：自己的每一趟。导入视频从这里开始：没有记录时，空状态引导第一段导入；有记录时，「导入这一趟」是页面上最大的按钮，下面是全部 / 已完攀 / 还在尝试的筛选和按名字或难度的搜索。不注入演示成绩。右上角进入「关于」：本地存储说明、分析边界、岩馆说明、隐私政策与支持。

底部导航固定，两项等宽，主行动面积大于 44pt。所有主图形旁有文字，颜色不单独表达状态。支持系统字体和可滚动页面；最大辅助字号和小屏真机仍需验收。

## 主任务流：回看一趟

1. 导入：在攀爬册点「导入这一趟」，从相册系统选择器或文件里选。只取用户选择的视频，不索取整个相册的读取权限。
2. 标记：可选名称、V 等级、完攀状态、一句话感受。难度与完攀由用户标记，模型不推断。
3. 精度：同一份 Full 权重，日常最高 10fps / 720px 长边，细看最高 15fps / 960px 长边；区别是采样与预处理。
4. 分析：真实解码进度，明确保持前台，可随时停止。模型缺失、视频无效、过长、超大、无可靠人体、温度过高均给可执行的错误信息。
5. 回看：原片 / 骨架、髋部短轨迹、时间轴、0.1 秒步进、0.5× 慢放。候选片段点击即定位并暂停。
6. 复盘：保存一句下一次想尝试的改变，更新完攀状态，分享复盘文字。

岩馆的任务流见 [gym-design.md](gym-design.md)。

## 分析诚实性

- 不展示「稳定性 93 分」「发力效率」等未经验证的评分。
- 髋部中点是图像几何代理，不叫物理重心。
- 肘角为经过宽高比校正的二维投影角度，不是关节的真实三维角度。
- 检测比例是「采样帧中左右髋部可靠的比例」，不是模型准确率或运动能力。
- 高抬脚只能生成「候选片段」，无法确认脚与岩点的接触，不能据此断言跟勾。
- 快速位移可能是动态、下落、镜头移动或追踪抖动，保留解释，不生成绝对诊断。
- 骨架不跨检测空白延续；置信度不足或出界的关键点隐藏。
- 岩馆内容标明非官方，可能与现场不符；推演是模型算出的一种可能，不说成最优解或教练建议。

这些说法在每种语言里都要成立。翻译时不许加强语气：不出现「精准」「最佳」「教练级」之类原文没有的承诺。

## 语言

界面支持简体中文、繁体中文、英语、日语、韩语，跟随系统语言；其他系统语言回落到简体中文（开发语言）。

- 所有面向用户的文字都在 String Catalog 里：界面、错误提示、空状态、按钮、无障碍标签、相册权限说明、分享出去的复盘文字。源码里不留只有一种语言的界面文字。
- 用攀岩的人实际说的话。英语用 send、projecting、beta、problem、hold；日语用完登、トライ、課題、ホールド；韩语用완등、시도、문제、홀드；繁体中文用路線、岩點、影片。beta 不翻。
- 日期、百分比跟随系统地区格式；时间码固定为 mm:ss；V 等级不翻。
- 胶囊标记和小号等宽英文（如 `KEEP IT HONEST`）是品牌标记，各语言都保持英文。
- 隐私政策随应用提供简体中文、繁体中文和英文三份；日语和韩语界面显示英文版。
- 用户自己写的内容（名称、笔记）原样保存和显示。未填名称时用保存那一刻的界面语言生成默认名称。回看里的候选片段按类型保存，换语言后显示对应语言的说明。
- 岩馆页面的语言由应用通过入口 URL 的 `lang` 参数告诉数据包；场馆名是数据，原样显示。

## 本地与恢复

姿态模型和场馆数据包随安装包提供；推理和存储无后端，岩馆页面不能访问网络。用户视频不进入本项目服务器；如果选择 iCloud 中未下载的原片，系统选择器可能先下载该原片。原片、缩略图和分析写入 Application Support，排除云备份，使用文件保护。JSON 原子写入；损坏的索引不被空记录覆盖；读到不认识的字段会忽略，不报错。

停止分析后可重新开始。没有后台续算和断点恢复。进入后台会取消任务；完成结果才写入记录。删除单条记录前使用系统确认，随后删除原片和分析。卸载会失去数据，因此提供明确说明和文字分享。

## 边界

iPhone，iOS 17+，竖屏。导入的视频：单人全身、固定镜头、0.5–180 秒、不超过 500 MB。

不做的事：应用内录像、多人时手动选人、从视频里分割岩点或判断手脚与岩点的接触、把骨架烧录进视频导出、训练计划与打卡、账号与同步、Android。
