# BetaBuddy iPhone · 产品与交互设计

## 产品性格

「再试一次。这次，有点不一样。」不是万能 AI 教练，而是懂攀岩节奏的随身回看手账：回看这一趟，记下来，带一个小练习上墙，再去岩馆看看同一条线换个身材怎么爬。成功、尝试、复盘都有位置。没有排行榜压力、虚构分数、连续打卡焦虑或首次打开的大段配置。

视觉语言：暖纸白 #F5F2E8、墨黑 #1A1F1A、荧光黄绿 #D1F24A、淡紫 #D1CCF0。超粗标题、紧凑英文运动标记配中文说明；倾斜的开口攀岩扣作为品牌标志，配合岩点与攀爬剪影形成自己的视觉识别。插画和图标为本地矢量绘制，首页不依赖远程图片。圆角控制在 14–26pt，强调色用于主行动与当前选择。

## 四个入口

- **上墙**：品牌海报、导入这一趟、真实记录计数、单个练习建议、最近一次回看。第一屏让用户知道该做什么。
- **攀爬册**：全部 / 已完攀 / 还在尝试，搜索线路名或难度。默认空状态引导第一段导入；不注入演示成绩。
- **练习**：三个短练习，每个聚焦一个可感知目标。练习建议是预置内容，与模型判断独立。完成后当天幂等记一次。

- **岩馆**：一家真实岩馆的 3D 线路图与「不同身材怎么爬这条线」的推演，来自随安装包内置的场馆数据包。非官方；推演不是建议。没有数据包的构建显示说明。设计与接口约定见 [gym-design.md](gym-design.md)。

底部导航固定，主行动面积大于 44pt。所有主图形旁有文字，颜色不单独表达状态。支持系统字体和可滚动页面；需在最大辅助字号及小屏真机继续验收。

## 主任务流：回看一趟

1. 导入：相册系统选择器 / 文件。只取用户选择的视频，不索取整个相册的读取权限。
2. 标记：可选名称、V 等级、完攀状态、一句话感受。难度与完攀由用户标记，模型不推断。
3. 精度：同一 Full 权重，日常最高 10fps / 720px 长边，细看最高 15fps / 960px 长边；区别是采样与预处理。
4. 分析：真实解码进度，明确保持前台，可随时停止。模型缺失、视频无效、过长、超大、无可靠人体、温度过高均给可执行错误信息。
5. 回看：原片 / 骨架、髋部短轨迹、时间轴、0.1 秒步进、0.5× 慢放。候选片段点击即定位并暂停。
6. 复盘：保存一句下一次想尝试的改变，更新完攀状态，分享复盘文字。

岩馆的任务流见 [gym-design.md](gym-design.md)。

## 分析诚实性

- 不展示“稳定性 93 分”“发力效率”等未经验证的评分。
- 髋部中点是图像几何代理，不叫物理重心。
- 肘角为经过宽高比校正的二维投影角度，不是关节的真实三维角度。
- 检测比例是“采样帧中左右髋部可靠的比例”，不是模型准确率或运动能力。
- 高抬脚只能生成“候选片段”，无法确认脚与岩点的接触，不能据此断言跟勾。
- 快速位移可能是动态、下落、镜头移动或追踪抖动，保留解释，不生成绝对诊断。
- 骨架不跨检测空白延续；置信度不足或出界的关键点隐藏。
- 岩馆内容标明非官方，可能与现场不符；推演是模型算出的一种可能，不说成最优解或教练建议。

## 本地与恢复

姿态模型和场馆数据包随安装包提供；推理和存储无后端，岩馆页面不能访问网络。用户视频不进入本项目服务器；如果选择 iCloud 中未下载的原片，系统选择器可能先下载该原片。原片、缩略图、分析和练习写入 Application Support，排除云备份，使用文件保护。JSON 原子写入；损坏的索引不被空记录覆盖。

停止分析后可重新开始。当前没有后台续算和断点恢复。进入后台会取消任务；完成结果才写入历史。删除单条记录前使用系统确认，随后删除原片和分析。卸载会失去数据，因此提供明确说明和文字分享。

## 边界

iPhone，iOS 17+，竖屏。导入的视频：单人全身、固定镜头、0.5–180 秒、不超过 500 MB。

不做的事：应用内录像、多人时手动选人、从视频里分割岩点或判断手脚与岩点的接触、把骨架烧录进视频导出、专业训练计划、账号与同步、Android。
