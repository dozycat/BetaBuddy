# Simplified Chinese storefront · English copy

For release 1.2.0, this storefront displays the English promotional text, description, keywords, What's New text, subtitle, support URL, and iPhone screenshots in [metadata-en.md](metadata-en.md). The app interface still supports Simplified Chinese when selected by the user or system.

The storefront remains configured with Simplified Chinese as its primary locale. Apple requires screenshots for every existing version before switching the primary locale to English; the live 1.0.0 version has no English screenshot set. This does not affect the English copy and screenshots prepared for 1.2.0. The live 1.0.0 listing may continue to display its older Chinese material until 1.2.0 is approved and released.
