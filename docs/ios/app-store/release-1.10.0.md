状态（2026-11-28）：构建 24 正式归档已完成，尚未上传或提审。导出 App Store IPA 时 Xcode 报 No Accounts 和缺少分发证书；App Store Connect 两个现有网页会话刷新后均回到登录框，等待恢复发布账户。用户已授权完成后直接正式发布，不需要再次确认发布意图。

内置数据包 1.10.2；Android 同步为 1.10.0（4），正式签名 APK 和 AAB 已生成，未上传商店。产物、验证及失败日志均在本机忽略目录 `ios/build/1.10.0/`。

## 更新内容

- 扫相册：主动开启后在设备上发现攀爬视频，按日期、岩馆归集；可修改推荐的环境和岩馆。
- 选人：自动选择或手动圈选，保存补选结果并用于分析、跟拍。时间轴显示已选区间，点「待补选」跳到缺失片段；重开保留已保存的选择。原视频背景保持不变。
- 剪辑：绳索样式的实际进度反馈，支持停止、重试。
- 精简导入、拍摄、列表和回看文字，保留必要操作与错误提示。

自动识别仍可能漏检，复杂遮挡可能需要补选；不承诺完整识别或遮挡后自动重认。路人消除仍未开放。旧记录可重新分析使用新流程。

- Swift 核心 39 项；Android JVM 204 项、299 条五语言资源、Debug／Release／AAB 与 lint 通过。
- 最终原生代码的 iOS 模拟器存档与重新分析检查、自动选人保存／重开 UI、未签名设备构建通过；签名归档成功。
- 归档与 Android Release APK 中的数据包 27 个文件与安装源逐字节一致，离线编码器存在，Android 编码器哈希匹配策略。正式 APK 签名和版本校验通过，无网络权限。
- 自然交叉、远景及分类的具体范围、失败与剩余限制见 [相机优化记录](../camera-library-selection.md)。工程检查不等于所有身份质量检查通过；本轮未追加真机。

- 构建 24 新增时间轴缺失跳转与保存选择的快速重开。iOS 真实 UI 保存／重开、无重推理回归和首次恢复回归通过；Android 缺失跳转、自动选择重开、选人保存／取消及首次恢复通过。复杂交叉质量的已知限制没有因这次界面改动消失。
