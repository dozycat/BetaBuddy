# iOS 1.10.0 (24)

状态（2026-11-28）：1.10.0（24）已上传并提交正式 App Store 审核。后台显示「正在等待审核」，提交弹窗确认「已提交 1 个项目」。审核通过后自动向所有用户发布，保留现有评分；尚未上线。中英文更新说明、审核备注及构建关联均已保存。

内置数据包 1.10.2；Android 同步为 1.10.0（4），正式签名 APK 和 AAB 已生成，未上传商店。产物、验证及失败日志均在本机忽略目录 `ios/build/1.10.0/`。

## 更新内容

- 扫相册：主动开启后在设备上发现攀爬视频，按日期、岩馆归集；可修改推荐的环境和岩馆。
- 选人：自动选择或手动圈选，保存补选结果并用于分析、跟拍。时间轴显示已选区间，点「待补选」跳到缺失片段；重开保留已保存的选择。原视频背景保持不变。
- 剪辑：绳索样式的实际进度反馈，支持停止、重试。
- 精简导入、拍摄、列表和回看文字，保留必要操作与错误提示。

自动识别仍可能漏检，复杂遮挡可能需要补选；不承诺完整识别或遮挡后自动重认。路人消除仍未开放。旧记录可重新分析使用新流程。
