1.1.0 的文案源和提审清单。后台实际状态见 [STATUS.md](STATUS.md)，流程见 [RELEASE.md](RELEASE.md)，通用商店文案见 [metadata-zh-Hans.md](metadata-zh-Hans.md) 和 [metadata-en.md](metadata-en.md)。场馆数据包不在本仓库里，构建前用 `ios/scripts/install-gym-pack.sh <数据包目录>` 装入（见 [../gym-design.md](../gym-design.md)）。

## 此版本的新增内容（What's New）

现在是两个入口：岩馆和攀爬册。

• 岩馆：在手机上看一座岩馆的非官方 3D 线路图，按岩壁、难度档和岩点颜色筛选线路；选择不同身材，看模型推演出的一种走法，可逐步回放。全部内置、离线可用。
• 攀爬册：导入一趟攀爬现在从这里开始。回看、笔记和完攀标记照旧。
• 界面支持简体中文、繁体中文、英语、日语和韩语。

岩馆内容为非官方整理，位置和线路可能与现场不符；推演结果不是教练建议，请以现场和自身判断为准。

英文版见 [metadata-en.md](metadata-en.md) 的 What’s New。
