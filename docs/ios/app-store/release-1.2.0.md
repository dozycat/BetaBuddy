# BetaBuddy 1.2.0 (7) 发布资料

后台实时状态见 [STATUS.md](STATUS.md)，操作流程见 [RELEASE.md](RELEASE.md)。本版本继续内置私有场馆数据包 1.2.1（72 条线路），构建前从私有仓库安装；场馆原始数据不进入本仓库。

## 此版本的新增内容（What's New）

增加可选的一次性终生会员内购。购买后，攀爬册立即显示终生会员标识；可在“设置与关于”恢复购买。岩馆与攀爬册的核心功能继续免费，没有订阅或广告。训练建议和新岩馆数据是后续计划，当前版本尚未提供。

界面继续支持简体中文、繁体中文、英语、日语和韩语，可跟随系统语言或在 App 内切换。

## 构建和商店设置

- App 版本 1.2.0、构建 7，已签名归档并上传，Apple 二进制文件状态“已验证”。
- 非消耗型内购 `com.betabuddy.ios.lifetime`，美国价格 $10；使用 StoreKit 2 的已验证交易授予权益。
- 首个内购需要随新版本一同提审；补齐内购审核截图后，在 1.2.0 版本页关联该项目。
- App 免费；隐私标签依据本构建实际行为填写。当前购买验证仅在设备上通过 StoreKit 进行，服务端核验尚未启用。
