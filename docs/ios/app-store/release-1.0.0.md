# BetaBuddy 1.0.0 发布资料

1.0.0 的内容与经过。后台实际状态见 [STATUS.md](STATUS.md)；通用流程见 [RELEASE.md](RELEASE.md)。

## 这个版本

- 三个入口：上墙、攀爬册、练习。内置 Pose Landmarker Full 模型，全部在手机上完成。
- 全部功能免费，无内购、订阅或广告；「关于」页写明。
- 应用内有离线隐私政策；公开的支持页与隐私政策已上线。
- 商店文案：[metadata-zh-Hans.md](metadata-zh-Hans.md) 中除「岩馆」以外的部分。截图：`screenshots-6.9/` 下三张 1320 × 2868 的真实界面。

## 构建

- **构建 1**：首次提交审核的构建。
- **构建 2**：修复一段用户视频里骨架落到背景上的误检、旋转视频的预处理，并支持保留笔记重新分析。排查记录见 [../pose-regression-2026-09-07.md](../pose-regression-2026-09-07.md)。已上传并分发给内部测试群组。

## 审核

2026-09-07，1.0.0 (1) 被 Apple 以 Guideline 2.1「Information Needed」拒绝：要求提供最新 iOS 真机上的全流程录屏，以及用途、操作步骤、外部服务和地区差异的说明。1.0.0 没有上架。
