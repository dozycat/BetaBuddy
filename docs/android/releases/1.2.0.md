- **Record inside the app.** "Record" opens the back camera (video only, no sound). While you frame the shot, the capture page bundled with the gym pack checks the camera position and picks out hold colours and holds; you choose the colour, tap the start and finish holds, and pick a grade and gym. The clip is saved first; pose recognition and the analysis then run on the phone by themselves.
- **Analyse an attempt.** On a reviewed clip, "Analyse this attempt" opens the analysis page from the bundled gym pack: it outlines the problem's holds found in the picture, walks through your hand and foot holds move by move with a paper-cut figure that follows your moves, and gives a few tips measured from this attempt. It is auto-detected, can be wrong and is not coaching advice. Results are saved with the record.
- **Gyms nearby.** On the capture screen you can sort the bundled gym directory by distance. Location is asked for only when you tap "Find gyms near me"; approximate or precise both work, the position is used once on the device and not saved.
- Videos save without pose analysis by default, so you can start reviewing immediately. Analysis continues after you leave the page or switch apps, and unfinished requests retry on the next launch. Android 13+ can show progress notifications; the notification permission is optional.
- Recording date and time are read from the video when available and can be edited during import or later.
- Folders, combined gym / grade / date filters and an offline gym directory in the logbook.
- Five languages (Simplified Chinese, Traditional Chinese, English, Japanese, Korean), switchable inside the app.

## Install and verification

Download the signed APK from GitHub Releases. Requires Android 8.0 or later.

- Permissions: camera (asked when you first open it), approximate and precise location (asked only when you tap "Find gyms near me"), optional notifications, and the local foreground service used for analysis. No internet, microphone, photo-library or storage permissions.
- Verified on the current code: resource checks (276 strings in five languages), 146 JVM unit tests, debug build and lint (no errors), with gym pack 1.9.8 bundled.
- Verified on emulators (Android 15 and 12) on earlier builds of this version: device tests for the capture screen and pose recognition, the release build after R8, the gym page and an offline network audit, the capture → save → pose recognition → analysis flow with stand-in pages and with real gym packs up to 1.9.3.
- Not yet verified: any physical Android device (camera, sensors, thermals, battery, background limits); the analysis page of gym pack 1.9.6 and later on Android; the system's location prompt; Android 8–11, 13–14 and 16+.
