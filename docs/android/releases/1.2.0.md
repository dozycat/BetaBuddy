# BetaBuddy Android 1.2.0 (2)

- Videos now save without pose analysis by default, so you can start reviewing immediately.
- Recording date and time are read automatically when available and can be edited during import or later.
- Optional analysis continues after you leave the page or switch to another app. Unfinished requests survive process termination and retry on the next launch.
- Android 13+ can show analysis progress notifications; notification permission is optional.
- Analysis results preserve notes, grade, date, and send-status edits made while work is running.
- Includes the logbook folders, combined filters, offline gym directory, and layout improvements since Android 1.1.0.

## Install and verification

Download the signed APK from GitHub Releases. Requires Android 8.0 or later. The signing certificate matches the previously published 1.1.0 APK, allowing an update without uninstalling or deleting local records.

- 80 JVM tests, 8 Android 15 emulator tests (including background completion), resource checks, debug build, and lint passed.
- Release APK and AAB built successfully with R8/resource shrinking and the configured release key.
- Bundled GymPack 1.3.9 files verified against the manifest. Pack contents remain outside the source repository.
- No network or photo-library permissions. Only local foreground-service and optional notification permissions were added.
- Physical-device power management, thermals, and Android 8–14 background behavior remain unverified in this iteration.

This follows the existing GitHub prerelease distribution channel; it is not a Google Play submission.
