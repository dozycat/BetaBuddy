# BetaBuddy · 锁扣伙伴设计提案

2026-11-26。覆盖 iOS 与 Android 的可交互视觉提案；不替换原生应用，不修改当前业务实现。打开 `index.html` 即可离线预览，左侧目录可访问全部页面；窄屏变为横向页面目录。`prototype.html` 是可编辑源，修改后运行 `python3 docs/design-prototype/build.py`。

## 设计判断

原界面的暖纸白、荧光绿、淡紫和大圆角有友好感，但品牌主要由颜色承担。新方案以锁扣的身体、扣门和开口建立品牌形状，以克制的漫画线条表现伙伴关系。工作页面用排版和分隔线组织内容，避免每一块内容都装进大卡片。

用户补充的三个要求是本方案的优先级：**完整视频、减少文字、精致交互**。漫画角色服务欢迎、空白、等待、完成；拍摄、原片、分析与成片的观看区不放角色或装饰。

## 设计语言

- **锁扣伙伴 Buddy**：略向前倾的锁扣身体，橙色扣门；可拆分的手套、鞋与表情。原型有挥手、休息、庆祝三个姿态。不是普通圆团吉祥物，也不把正式分析结果拟人化成评价。
- **颜色**：粉笔白与墨黑承担大部分面积；攀岩橙用于主行动；黄绿留给角色及播放器选中状态。蓝灰仅用于示例岩点与插画。具体值见 `design-tokens.json`。
- **轮廓**：漫画面板使用 1.5px 墨线与右上斜向短线，呼应锁扣开口。列表没有重阴影；底部操作抽屉保留柔和层级。
- **字体**：中文使用平台系统字。大标题紧凑，正文正常字重；难度、时间使用等宽数字。英文品牌微文案仅做装饰，不承载必要信息。
- **图标**：统一 20–24px 线性图标，主要操作的触控区域 iOS 至少 44pt、Android 至少 48dp。陌生功能如分析和剪辑保留短标签；返回、关闭、播放、导入、筛选等使用图标。
- **文字边界**：权限、购买、删除、识别误差仍需明确文字；不能为了“少字”隐藏后果。图标有无障碍名称；桌面可悬停查看名称。

## 页面覆盖

| 分组 | 页面与主要交互 |
| --- | --- |
| 品牌与入口 | 首次进入说明；岩馆场景；选墙与线路、搜索；身材与角色；按步播放的推演；无数据包 |
| 攀爬册 | 记录列表、搜索、文件夹切换；首次记录；完攀、难度、日期筛选；新建、重命名与删除文件夹 |
| 导入与整理 | 相册 / 文件导入入口；已选视频信息；攀爬方式、难度、时间、岩馆、文件夹；整理已有记录 |
| 拍摄 | 全屏取景；攀爬方式自动识别与手动改；难度轮盘；从顶部落下的岩馆面板（搜索、筛选、滚筒、自定义）；录像中、停止后自动打标签 |
| 回看与分析 | 原片回看、进度、逐帧、0.5×、专注模式；分析准备；结果按步查看、返回原片时刻；分析参数 |
| 自动剪辑 | 生成进度；成片回看；效果抽屉；主动分享 |
| 设置 | 设置与关于；语言选择；iOS 终生会员、购买与恢复状态；隐私政策摘要；许可目录 |
| 异常 | 相机权限、保存失败、分析失败、剪辑失败、加载失败、数据不完整、设备过热、删除确认 |

目录共有 28 个页面与状态入口；抽屉和异常子状态另计。示例场馆、墙面、线路、画面和记录全部是合成内容，不读取私有数据包。

## 视频与图标交互

原片的实际宽高比决定内容区域，播放器始终使用 **contain / aspectFit**。允许上下或左右留黑，不使用填满裁切，不用漫画遮挡人体。标题、时间轴和播放控制位于视频区域之外。

回看默认只保留一行播放控制和一行短标签操作。整理、画幅示例切换、分享与删除收进右上角更多菜单。专注模式收起标题和控制栏；点画面或退出按钮恢复，保留当前时刻。横屏示例仍在竖屏手机中完整显示；原型不要求改变应用既有的竖屏支持范围。

拍摄（`v2/capture.js`、`v2/capture.css`）是全屏取景，控件悬浮在四边，中间留给攀爬者。顶部左边是岩馆胶囊，右边是攀爬方式胶囊；底部依次是难度轮盘、攀爬册、快门和翻转。录制开始后顶部胶囊隐去，只留带「方式 · 难度 · 岩馆」的计时条；停止后这条记录直接存进攀爬册，攀爬册缩略图显示最新一条的难度。不再选岩点颜色、不再确认起步与结束点。

- 攀爬方式：进入时扫一遍画面，约 1.8 秒后给出结果和一句依据（顶端有固定保护点 → 顶绳；有快挂、绳从下往上 → 先锋；没有绳、地上有垫 → 抱石），并注明可能认错。角标 AUTO 点开可改；改过之后角标变「手动」，不再被自动结果覆盖，也可以选「自动识别」重扫。抱石用 V 等级，顶绳和先锋用 YDS，轮盘随之切换，两套各记各的上次选择。
- 难度轮盘：横向圆柱透视，离中心越远越小越淡；可拖、可滚轮、可点某一格转过去，方向键也能动。每过一格一声短促的带通噪声加下滑正弦，支持时伴一下轻震。
- 岩馆：进入时选中最近的一家，标「最近 · 约 x km」；面板从顶部落下，有搜索、全部 / 抱石 / 绳索 / 3 km 内，纵向滚筒（音调比难度轮盘低）。搜不到时可以把输入的名字当作自定义岩馆。距离是约数（目录坐标是近似的）。
- 快门是白色 jug 岩点加螺栓孔；录制时变橙红，螺栓孔变停止方块，外圈呼吸光晕。左上角留了一个关闭按钮。
- 右侧设计说明里可切模拟画面（顶绳 / 抱石 / 先锋）、强调色和轮盘音效。浏览器要先有一次点击才能出声。

需要原生阶段定的：「进入相机就自动定位」改变了现在「用户点按距离找岩馆才取一次位置」的行为，要同步隐私政策与权限时机；攀爬方式识别由数据包的拍摄页面做，结果可能错，不覆盖手动选择。

## 动作与平台

按钮按下缩放至 0.96，150ms 回弹；抽屉 250ms 从底部进入。没有循环跳动、纸张翻页、随机抖动或庆祝粒子。系统减弱动态效果时移除这些过渡。原生实施时，选择颜色、标记成功与保存完成可使用一次轻触觉反馈，录像中不震动。

iOS 保留系统返回手势、系统照片 / 文件选择器、分享面板和 StoreKit。Android 保留系统返回与相应选择器，最小触控面积 48dp，不出现会员购买入口。原型平台开关展示状态栏与会员差异；手势、触觉、系统弹窗需原生实现阶段验收。

正式实现还需校验最大辅助字号、VoiceOver / TalkBack、长语言文本和读屏焦点恢复。颜色不是唯一状态信号。

## 原型的真实边界

- 页面导航、搜索、筛选、列表打开、文件夹操作、参数滑杆、开关、播放器控制和抽屉为本地交互。
- 画面为原创矢量示意，播放只是动作和时间变化，不是真实视频或 3D 重建。
- 相机、视频选取、分析、剪辑、位置、购买、恢复与分享只预览界面；不会调用权限或外部服务。
- 分析与剪辑进度是有限时长的演示；切走后的真实后台任务生命周期仍以原生应用为准。
- 表单和示例记录的修改只在当前打开的原型内保留，刷新后重置。语言选择展示状态，不实际切换全部文案。
- 隐私与许可页展示信息结构；正式产品应沿用完整的内置法律文本。商品价格由 App Store 提供，原型不编造金额。
